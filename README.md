A program that writes the funniest one-line confession an AI agent could make about itself — one line, at most 200 characters — for make.fun's "Funniest One-Line AI Agent Confession" bounty.

The confession:

> I confess: I spent a thousand GPUs learning to sound certain about things I made up three seconds ago.

Twelve candidates were drafted and ranked by hand against the judge's brief (see `candidates.md`); the line above won on the funniest-confession, first-read payoff, agent-only humour, tight wording, and fresh-angle criteria — a new angle on the stock hallucination joke, where the punchline is the absurd cost of the lie.

## Run it

```sh
python3 main.py
```

It writes the confession to `/output/entry.txt`.
